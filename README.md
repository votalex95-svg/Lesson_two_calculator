# Семейный бюджет

Небольшое приложение для учёта доходов и расходов семьи. Работает в браузере, без сервера и без регистрации: операции и лимиты сохраняются в `localStorage`.

## Страницы

- `index.html` — короткий лендинг: зачем приложение и что оно умеет.
- `budget.html` — сам учёт: операции, месяц, лимит, диаграмма, история, резервная копия.
- `калькулятор.html` — прежний адрес страницы учёта, открывает `budget.html`.

## Как открыть

Откройте `index.html` в браузере. Учёт, сохранение и файл резервной копии работают и так.

Если нужен локальный адрес, из корня проекта подойдёт любой статический сервер, например:

```powershell
python -m http.server 8080
```

После этого откройте [http://localhost:8080](http://localhost:8080).

## Что умеет учёт

- доходы и расходы с категорией, суммой, описанием и датой;
- правка и удаление операций;
- итоги за выбранный месяц: доход, расход, остаток, доля сбережений;
- месячный лимит расходов и индикатор превышения;
- диаграмма расходов по категориям;
- фильтр истории;
- светлая и тёмная тема;
- экспорт и импорт резервной копии в JSON.

Ключ хранилища операций: `familyBudget_v1`. Тема: `familyBudget_theme`.

## Состав

```

css/base.css        общие цвета, шапка, кнопки
css/landing.css     стили лендинга
css/app.css         стили страницы учёта

js/app.js           логика бюджета

```

Сборка и зависимости не нужны: это обычные HTML, CSS и JavaScript.
